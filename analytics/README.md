# Business Analytics

This folder contains SQL analyses that answer business questions using the Gold layer.

## Conventions
- Query the Gold model wherever possible.
- Store reusable business-question queries in `sql/`.
- Store curated, presentation-ready outputs in `reports/`.
- Define the grain and calculation for every metric.
- Validate joins and totals before publishing conclusions.

## Planned analysis
- Customer behavior and customer segmentation.
- Product and category performance.
- Sales trends and seasonality.
- Revenue, quantity, order, and average-price KPIs.
- Period-over-period and cumulative performance.
